# 文隐下载

[English](README.md)

文隐是 Mac 本机运行的文书脱敏工具。本仓库仅分发 DMG 安装包，不包含应用源码；源码保持私有。

从[发布页](https://github.com/songoao25/wenyin-downloads/releases)或[文隐下载页](https://brickindex.pages.dev/#/service/wenyin)下载。当前为 **1.3.0（构建 220）内测版**，适用于 Apple 芯片 Mac，目标系统为 macOS 12 或更新版本。

打开 DMG，将文隐拖入 Applications，再打开应用。当前安装包不做 Apple 公证。若系统阻止打开，先尝试打开一次，再到系统设置 → 隐私与安全性，为文隐选择“仍要打开”；macOS 12 对应系统偏好设置 → 安全性与隐私。不要关闭系统安全保护。

导入 DOCX 或文字型 PDF，逐项复核识别结果，并检查导出的副本。识别仍有遗漏，不能仅依赖自动识别。暂不支持扫描件。

默认自动检查新版，左下角黄色图标提示；点击后下载、安装并重新打开。设置中可选择自动或手动更新。文稿处理留在本机；更新与下载服务会收到网络请求，不上传文稿或使用统计。
