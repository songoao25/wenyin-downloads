# 文隐下载

文隐是一款本机 macOS 应用：把文书交给 AI 之前，先在本机识别并替换敏感信息。这个公开仓库只分发安装包，应用源码不公开。

## 下载

| 你的网络 | 线路 | 地址 |
| --- | --- | --- |
| 中国大陆 | Gitee（国内速度快） | https://gitee.com/songoao25/wenyin-downloads/releases |
| 海外 / 有代理 | GitHub（本仓库） | https://github.com/songoao25/wenyin-downloads/releases |

两条线路发布的是同一份构建。大陆网络访问 GitHub 经常很慢或打不开，所以优先用 Gitee；在海外则 GitHub 通常更快。应用内也可以在**设置 → 更新**里切换两条更新线路。

当前版本：**2.0.6（构建 248）**，Apple 芯片 Mac，macOS 12 或更新版本。

版本留存：本仓库保留全部历史版本；Gitee 镜像因为单仓库附件总量 1GB 的限制，只保留最近 3 个版本。

## 安装

打开 DMG，把文隐拖进「应用程序」，然后启动。安装包未公证：如果被系统阻止，先试着打开一次，再到「系统设置 → 隐私与安全性」里为文隐选择「仍要打开」（macOS 12 是「系统偏好设置 → 安全性与隐私」）。不需要关闭系统安全保护。

导入 DOCX 或文字型 PDF，逐项复核识别结果，再检查导出的副本。识别会遗漏，请逐项核对；扫描件不支持。文书只在本机处理，联网只用于检查更新，文稿和使用统计都不会上传。
